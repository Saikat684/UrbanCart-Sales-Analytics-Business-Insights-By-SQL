📊 UrbanCart Sales Analytics – Business Insights Using SQL

Project Overview

This project analyzes UrbanCart's sales and customer data using SQL (PostgreSQL) to generate actionable business insights.
The goal is to support data-driven decisions related to:

Revenue growth

Customer behavior

Product performance

Inventory risk

Payment method optimization

The dataset represents a multi-city e-commerce operation processing thousands of orders monthly.

Tools & Technologies

PostgreSQL

SQL (Joins, CTEs, Aggregations, Window Functions)

GitHub Markdown for Documentation

📈 Business Questions Answered

Which cities generate the highest revenue?

Who are the top customers?

Which products are frequently bought together?

What payment methods are most used?

Which products are at risk of stock-out?

What is the monthly order trend?
